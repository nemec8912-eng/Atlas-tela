# Атлас тела

Интерактивный 3D-атлас тела человека на русском языке. Тело можно вращать, разбирать на детали, включать и выключать системы органов, искать любую структуру и смотреть её отдельно.

- **2 967 деталей**, около 4,9 млн треугольников (детализация примерно вдвое выше исходного проекта).
- **Всё на русском**: интерфейс и названия ~2 400 анатомических структур, оригинальное название показано в карточке.
- **Кровеносная система** (сердце, артерии, вены) и **нервная система** отдельными группами.
- **Кожа** и **волосяной покров** — отдельные слои.
- **Две детализации**: обычная (2,3 млн треугольников, ~14 МБ) и высокая (4,9 млн, ~30 МБ). На слабых устройствах обычная включается сама; выбор запоминается.
- **Подписи на модели** — названия видимых структур прямо на теле, нажатие открывает карточку.
- **Срезы** — плоскость сверху, спереди или сбоку показывает тело в разрезе на любом уровне.
- **Тест** — «Что это?» (выбор из четырёх) и «Найди на теле», со счётом.
- **Поиск по бытовым словам**: «бицепс», «ахилл», «кадык», «пресс»; для отсутствующих в модели структур (копчик, мимические мышцы) поиск об этом сообщает.
- **Описания** у ~1 750 деталей: все кости, основные мышцы, органы, главные сосуды и нервы.
- **Офлайн**: при открытии с GitHub Pages сайт кэшируется и устанавливается на экран телефона как приложение.

## GitHub Pages

В репозитории есть workflow `.github/workflows/pages.yml`, который публикует папку `site/` при каждом push в `main`. Чтобы он заработал, один раз откройте **Settings → Pages** и в поле **Source** выберите **GitHub Actions**. Для приватного репозитория GitHub Pages доступен только на платном тарифе — иначе сделайте репозиторий публичным.

Адрес сайта: `https://nemec8912-eng.github.io/Atlas-tela/`

## Запуск

Готовый сайт лежит в папке `site/` — это статические файлы, их можно открыть через любой веб-сервер или выложить на GitHub Pages / Vercel / Netlify.

```bash
npm run serve        # http://localhost:8000
```

Пересборка интерфейса после правок в `app/`:

```bash
npm install
npm run build:site   # пишет site/app.js и site/app.css
```

## Откуда данные

Модели — **BodyParts3D / Anatomography 4.3** (© Database Center for Life Science, DBCLS), лицензия **CC BY-SA 2.1 Japan**. Полный набор взят из репозитория [olivercase/body_parts_3d_api](https://github.com/olivercase/body_parts_3d_api).

Основа интерфейса — [Human Atlas](https://github.com/ashemag/human-atlas) (MIT).

### Что добавлено и исправлено по сравнению с исходным проектом
- Полный перевод на русский, правильная запись сторон («левый желудочек», а не «желудочек (лев.)»).
- Исправлено распределение по системам: желудочки мозга не в «Сердце», мышцы не в «Скелете», сегменты печени не в «Венах» и т. д.
- Геометрия заменена на полный набор 4.3 с более мягким упрощением; добавлено ~500 новых структур: щитовидная и паращитовидные железы, венозные синусы мозга, ядра гипоталамуса, рёберные хрящи VIII–X, сосуды головы и шеи, плечевое сплетение и нервы руки.
- Нервы, которые в данных есть только слева, показаны справа зеркальной копией (отмечено в карточке).
- **Схематичные нервы.** Нервов ног, поясничного и крестцового сплетений, межрёберных нервов III–XII и симпатического ствола в BodyParts3D нет — они построены программно по ходу позвоночного канала, рёбер и сосудов модели (`data-pipeline/nerves.py`) и помечены в карточке как схема.

### Чего нет
В BodyParts3D отсутствуют широчайшая мышца спины, прямая, внутренняя косая и поперечная мышцы живота, квадратная мышца поясницы, жевательные и мимические мышцы, копчик и слуховые косточки.

## Формат геометрии (`codec: vq1`)

Каждая деталь хранится в чанке `site/models/geo-N.bin.gz.txt` (gzip → base64):
позиции квантованы в 16 бит относительно рамки детали, закодированы дельтами по осям (zigzag + varint);
индексы — смещение от «верхней отметки» (varint). Нормали считаются в браузере. Декодер — в `app/scene.tsx`, без WebAssembly.

## Сборка данных (`data-pipeline/`)

| Скрипт | Что делает |
|---|---|
| `prep.py` | разбирает OBJ BodyParts3D 4.3, сваривает вершины, упрощает meshoptimizer (50 %, ошибка 0,1 %) |
| `match.py`, `dedupe2.py`, `classify.py` | сопоставляет детали с атласом, отсеивает дубли, определяет систему |
| `nerves.py` | строит схематичные нервы |
| `rename.py`, `translations/*.tsv` | русские названия |
| `build2.py`, `postfix.py` | собирает `atlas.json` и чанки высокой детализации, исправляет системы, добавляет описания из `desc.tsv` |
| `LEVEL=lo build2.py`, `merge_lo.py` | собирает облегчённую геометрию (`prep.py` с `RATIO=0.2 ERR=0.003`) и вписывает её в `atlas.json` |

Пути в скриптах указывают на рабочие папки сборки — поправьте их под себя.

Это учебный справочник, а не инструмент для диагностики или хирургии.
